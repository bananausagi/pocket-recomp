# v0.2.91-personal.1（versionCode 95 / 0.2.91-jp.91-personal）

## 位置づけ

jp 系列の最終配布版 jp.91-preview2 に、未ビルドだった作業ツリー（game91）の変更を統合し、ごちゃごちゃしていた系統を単一の個人用ビルドラインに作り直した初版です。

## 内容

- 3D 戦闘背景を、同梱 MOD「DRAMALESS_SHAPE」（2.0.28+jp.20 final）経由の描画に切り替え（WIP だった作業分）
- MOD のアップグレード基盤を追加（upgrades-jp91p2）
- 起動時の更新通知を追加： GitHub Releases の version.json を確認し、新しい版があればランチャーにバナーを表示します（タップで Releases ページへ）
- ビルド手順を単一の build.py に再構成

## 注意（初回インストール前にお読みください）

- **署名鍵が jp 系列と異なります。** jp.91-preview2 など旧版の上には上書きインストールできません。初回は、大切なセーブを先に書き出して保管し、旧版をアンインストールしてから本版を新規インストールしてください。本版以降の個人用ビルド同士は同じ鍵なので、上書きで更新できます。
- 本版は実機での動作確認をしていません。WIP だった作業分を含むため、表示や動作に問題が出る可能性があります。
- ROM は同梱していません。遊ぶには、利用者自身が用意した ROM が必要です。
