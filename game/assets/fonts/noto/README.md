# Noto Sans JP Regular

Japanese launcher font from the official Google Fonts repository. The bundled
font remains under the SIL Open Font License 1.1; see `OFL.txt`. It is not
covered by this application's license. The reserved font name in the upstream
license is "Source", which is not used for this font.

The upstream variable font was instantiated at `wght=400` with fontTools
4.61.1, `instantiateVariableFont(..., inplace=False, updateFontNames=True)`.
The full Unicode cmap (16,732 entries) was retained; no glyph subsetting or
outline editing was performed. The result is a static TrueType font for
compatibility with the app's existing FreeType runtime. `recalcTimestamp` was
set to `False` before saving.

Exact download URLs, source revision information, SHA-256 hashes and the
transformation record are in `provenance.json`. The source is
[Google Fonts Noto Sans JP](https://github.com/google/fonts/tree/main/ofl/notosansjp).
